🔀 Parallel

Two independent Units at once

event-ingest and preferences-api don't depend on each other. Marcus runs one Claude session per git worktree, so they never edit the same checkout.

bash
$ git worktree add ../ns-ingest -b unit/event-ingest $ git worktree add ../ns-prefs -b unit/preferences-api # terminal tab 1 $ cd ../ns-ingest && claude # terminal tab 2 $ cd ../ns-prefs && claude

Local worktrees

Full control, your machine's tools, one terminal tab per session.

Cloud sessions

Start each Unit as a Claude Code web session on its own branch. Check progress from your phone; the session pushes a branch for review.

ℹ️

AI-DLC's Construction swarm does the same thing with a referee: it claims a worktree per Unit and blocks cross-Unit writes.
