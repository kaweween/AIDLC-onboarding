Step 1
📦 Install

Install the CLI and sign in

bash
$ npm install -g @openai/codex # or: brew install --cask codex added 1 package $ cd ~/src/billing-platform && codex Sign in with ChatGPT · or provide an API key Signed in (Contoso workspace). Trust this folder? [Yes] → project config in .codex/ will be used
💡

On Windows, run Codex in WSL for the best sandbox support, unless your version's docs say native Windows is fully supported.

🛡️ Policy

Two dials: what it can do, and when it asks

Pick a combination and a request to see what happens. Exact menu names differ between CLI versions; the two dials stay the same.

⚠️

Team default: workspace-write + on-request. Use read-only to explore unfamiliar code. Keep danger-full-access + never for disposable containers only.

🧾 Config

Write the defaults down

.codex/config.toml (project, committed)
sandbox_mode = "workspace-write" approval_policy = "on-request" [sandbox_workspace_write] network_access = false # restore once, then work offline [profiles.explore] # codex --profile explore sandbox_mode = "read-only" [mcp_servers.ado] command = "npx" args = ["-y", "@azure-devops/mcp", "contoso"]
ℹ️

Personal settings (model choice, your own MCP servers) go in ~/.codex/config.toml. You can also add servers with codex mcp add. Check key names against codex --help and the config reference for your version.

📝 Repo

Draft AGENTS.md with /init, then keep only what matters

AGENTS.md
# billing-platform ## Commands - Build: dotnet build BillingPlatform.sln - Test (required before finishing): dotnet test --filter Category!=Slow ## Conventions - xUnit + FluentAssertions + NSubstitute; test first; never change a test to make it pass. - Never log PII (email, IBAN); use Redact(). - Public API change ⇒ update api/openapi.yaml. ## Review guidelines - Flag PII in logs, missing tenant checks, and sync I/O in request paths as P1. - Ignore formatting; dotnet format handles it.

@codex review on GitHub reads the "Review guidelines" section, so one file steers both coding and reviewing.
