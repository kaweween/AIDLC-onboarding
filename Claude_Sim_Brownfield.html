🤖 Ops

When the deploy smoke test fails, Claude explains it in the PR

The pipeline runs Claude in headless mode with read-only tools and posts a summary. It doesn't fix anything on its own.

.github/workflows/deploy.yml (failure step)
- name: Explain failure if: failure() run: | claude -p "Read smoke.log and the last deploy diff. Explain the most likely cause in 5 lines and suggest a fix. Do not edit files." \ --allowedTools "Read,Grep,Bash(git diff:*)" \ --output-format json > triage.json gh pr comment "$PR" --body "$(jq -r .result triage.json)"
